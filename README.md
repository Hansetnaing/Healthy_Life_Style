# Wellbeing Guide

A responsive student website about physical health and mental wellbeing.

## Project structure

```text
assets/
  css/styles.css       Shared site styling
  images/              Site image assets
  js/main.js           Mobile navigation and contact-form feedback
pages/                 Secondary site pages
index.html             Home page
```

## Run locally

Open `index.html` in a browser, or use a local static-server extension in VS Code. The contact form is a front-end demonstration and does not send messages.
